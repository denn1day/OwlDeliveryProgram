\- инициализация репозитория;

\- работа с ветками main, develop, feature/\*;

\- merge --no-ff;

\- rebase;

\- cherry-pick;

\- revert;

\- reset --soft;

\- reset --hard;

\- restore;

\- Git Hooks;

\- разрешение конфликтов;

\- теги версий.
